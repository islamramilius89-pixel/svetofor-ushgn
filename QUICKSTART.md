# 🚀 Быстрый старт

## Установка и запуск (3 шага)

### 1️⃣ Установите зависимости
```bash
npm install
```

### 2️⃣ Запустите dev-сервер
```bash
npm run dev
```

### 3️⃣ Откройте в браузере
Перейдите на `http://localhost:5173`

---

## 📝 Что делать дальше?

### Просмотреть функционал:
- 🏠 **Home** (`/`) — главная страница с метриками
- 📖 **About** (`/about`) — информация о проекте
- 📊 **Results** (`/results`) — результаты ОПИ
- 📧 **Contact** (`/contact`) — форма обратной связи

### На странице Contact попробуйте:
1. Заполнить форму (Имя, Email, Сообщение)
2. Нажать "Отправить"
3. Увидеть сообщение в списке ниже
4. Удалить сообщение кнопкой ✕
5. Очистить все сообщения
