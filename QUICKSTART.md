# 🚀 Быстрый старт

1. Установить всё и создать базу с тестовыми данными (один раз):

   ```bash
   npm run setup
   ```

2. Запустить фронтенд и бэкенд:

   ```bash
   npm run dev
   ```

3. Открыть http://localhost:3000.

## Что попробовать

1. **Скважины** — нажмите «Срочно проверить», найдите скважину по номеру, отметьте ★ и включите фильтр «Избранные». Скопируйте адрес страницы: фильтры сохраняются в нём.
2. Откройте скважину и нажмите **«Создать заявку»**.
3. **Заявки** — перетащите карточку из «Новые» в «В работе», затем в «Проверено». Вернитесь к скважине: дата последней проверки обновилась.
4. Откройте заявку и добавьте **комментарий**. При следующем комментарии имя подставится само.
5. **Контакты** — отправьте сообщение.
6. **Админ-панель** (ссылка внизу страницы): логин `admin`, пароль `svetofor-admin`. Добавьте скважину с отклонением 30% и посмотрите, как она станет красной. Прочитайте сообщение из формы.

## Если что-то пошло не так

- **«Сервер API недоступен»** — бэкенд не запущен. Используйте `npm run dev`, а не `next dev`.
- **Нужно вернуть исходные данные** — `npm --prefix backend run db:seed`.
