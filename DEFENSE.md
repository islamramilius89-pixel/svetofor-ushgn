## 3️⃣ Технологический стек

### Выбранные технологии:

```
┌─────────────────────────────────────┐
│         Frontend Framework           │
├─────────────────────────────────────┤
│ Vue 3 (Progressive JavaScript)      │
│ + Vue Router (Routing)              │
│ + Pinia (State Management)          │
│ + Tailwind CSS (Styling)            │
└─────────────────────────────────────┘
```

### Почему именно эти технологии?

**Vue 3:**
- Современный, быстрый и легко изучаемый framework
- Отличная документация и большое сообщество
- Composition API для чистого и модульного кода
- Идеален для учебных проектов и production

**Vue Router:**
- Официальное решение для маршрутизации в Vue
- Позволяет создавать многостраничное SPA приложение
- Поддержка History API для красивых URL

**Pinia:**
- Современный state manager для Vue 3 (рекомендуемый)
- Проще, чем Vuex, но мощнее Context API
- Отлично подходит для управления состоянием приложения

**Tailwind CSS:**
- Утилитарный CSS фреймворк для быстрого дизайна
- Встроенная адаптивность (mobile-first)
- Нет необходимости писать кастомный CSS

**Vite:**
- Быстрая сборка и dev-сервер
- Отличная поддержка Vue 3
- Быстрая горячая перезагрузка (HMR)

## 6️⃣ Vue Router и маршрутизация

### Конфигурация маршрутов:

```javascript
// src/router/index.js
const routes = [
  { path: '/', component: Home, name: 'home' },
  { path: '/about', component: About, name: 'about' },
  { path: '/results', component: Results, name: 'results' },
  { path: '/contact', component: Contact, name: 'contact' },
]

const router = createRouter({
  history: createWebHistory(),
  routes,
})
```

### Как это работает?
1. Определяем массив маршрутов (path → component)
2. Создаем router экземпляр с History API
3. Используем `<router-link>` для навигации
4. Используем `<router-view>` для отображения компонента

### Преимущества:
- ✅ Быстрая навигация без перезагрузки страницы
- ✅ История браузера работает корректно
- ✅ URL изменяется, но страница не перезагружается
- ✅ Красивые ссылки (например: `/about`, а не `?page=about`)

### Как использовать в компонентах:

```vue
<script setup>
import { useLightStore } from '../stores/lightStore'
const store = useLightStore()
</script>

<template>
  <!-- Чтение из store -->
```

## 🔟1️⃣ Возможные вопросы и ответы

**Q: Почему выбран Vue 3, а не React?**  
A: Vue 3 проще в изучении, имеет лучшую документацию для начинающих, и Composition API очень удобен для структурирования кода.

**Q: Зачем нужен Vue Router, если это лендинг?**  
A: Это демонстрирует создание полноценного SPA, не просто лендинга. Роутинг позволяет управлять разными страницами без перезагрузки.

**Q: Как Pinia помогает в этом проекте?**  
A: Pinia используется для сохранения сообщений пользователей на странице Contact. Это демонстрирует знание state management и позволяет легко масштабировать приложение.

**Q: Может ли это приложение подключить API?**  
A: Да! Легко можно добавить запросы к API (fetch или axios) и сохранять данные в Pinia store.

**Q: Как это приложение может быть развернуто?**  
A: После `npm run build` создается папка `dist/` с готовым приложением. Его можно развернуть на Vercel, Netlify, GitHub Pages или любом хостинге.
