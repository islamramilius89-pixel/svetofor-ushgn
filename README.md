# 🚨 Светофор УШГН - SPA/Лендинг

## 📋 Описание проекта

**Светофор УШГН** — это Single Page Application (SPA) лендинг, посвященный инновационной системе мониторинга и диагностики скважин компании ПАО "Татнефть". Проект демонстрирует возможности применения веб-технологий в нефтегазовой промышленности.

### Назначение
Приложение служит информационным порталом о системе "Светофор", выполняя функции:
- Информирование о проекте и его целях
- Представление результатов опытно-промышленной эксплуатации (ОПИ)
- Демонстрация технологии и методологии
- Сбор обратной связи от пользователей

---

## ⚙️ Технологический стек

### Frontend Framework
- **Vue 3** — современный progressive JavaScript framework
- **Vue Router** — маршрутизация между страницами
- **Pinia** — state management (управление состоянием)
- **Vite** — быстрая сборка и dev-сервер

### Стилизация
- **Tailwind CSS** — утилитарный CSS фреймворк для быстрого дизайна
- **PostCSS** — обработка CSS

### Инструменты разработки
- **Node.js** + **npm** — управление зависимостями
- **Git** — контроль версий

## 🔧 Технические особенности

### Vue Router (Маршрутизация)
```javascript
// Все маршруты определены в src/router/index.js
const routes = [
  { path: '/', component: Home },
  { path: '/about', component: About },
  { path: '/results', component: Results },
  { path: '/contact', component: Contact },
]
```

### Pinia Store (State Management)
```javascript
// src/stores/lightStore.js содержит:
// - State: wells, wellsWithDeviations, downtimeFound, userMessages
// - Computed: completenessPercentage, messageCount
```

Это позволяет:
- Сохранять состояние приложения
- Обмениваться данными между компонентами
- Управлять сообщениями пользователей

### Компонентная архитектура
- Переиспользуемые Vue компоненты
- Разделение логики и представления (script setup syntax)
- Эффективное управление состоянием

## 📝 Примечания для защиты

### Что спрашивать преподаватель:

**Q: Почему выбран Vue 3?**  
**A:** Vue 3 — это современный framework с простой кривой обучения, отличной документацией и высокой производительностью. Composition API позволяет писать более чистый код.

**Q: Зачем нужен Pinia?**  
**A:** Pinia — это state manager, который позволяет управлять состоянием приложения централизованно. В нашем случае она используется для сохранения сообщений пользователей и метрик.

**Q: Как работает Vue Router?**  
**A:** Vue Router позволяет создать многостраничное приложение без перезагрузки страницы. Маршруты определены в router/index.js, каждому маршруту соответствует компонент.

**Q: Почему Tailwind CSS?**  
**A:** Tailwind предоставляет готовые утилиты для быстрого создания дизайна, без написания кастомного CSS. Это ускоряет разработку и обеспечивает единообразный стиль.

**Q: Может ли это приложение масштабироваться?**  
**A:** Да! Структура проекта позволяет легко добавлять новые страницы, компоненты, интегрировать API, подключить базу данных и т.д.
